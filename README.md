# Botmaker Assignment

A React + TypeScript + Tailwind CSS project. 

### Project Deployed URL - https://botleague-assignment-vibek.netlify.app/

## Prerequisites

- Node.js 18 or newer
- npm

## Clone the Repo

```bash
git clone https://github.com/champati-v/BotMakers-Full-Stack-Assignment.git
```

## Navigate to folder
```bash
cd BotMakers-Full-Stack-Assignment
```

## Setup

Install the dependencies:

```bash
npm install
```

## Run Locally

Start the development server:

```bash
npm run dev
```

Vite will print the local URL in the terminal. Open http://localhost:5173/ your browser to view the app.
